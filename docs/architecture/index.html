01 / 用户表达

只听用户亲口说的

以用户最终说出的内容为事实来源，不把数字人的回答和推测当作记忆。

02 / 发现重点

识别值得记住的内容

发现姓名、人物关系、重要事件，以及“请记住”这类明确表达。

03 / 本地保存

形成长期记忆

确认度高的内容长期保留；不确定的信息先作为候选，等待后续确认。

04 / 相关召回

只找此刻有用的记忆

回答当前问题前，找到少量相关内容，帮助大模型理解人与事情的来龙去脉。

05 / 连续陪伴

给出更贴近你的回应

不同对话路线都能结合记忆继续交流，也能在合适的时候自然关心重要事件。

本机私有

记忆数据只保存在当前电脑，不上传记忆数据库，也不保存录音、密钥或整段聊天记录。

随时可管理

可以搜索和查看记忆，逐条删除，也可以在确认后清空全部内容。

安全迁移

支持导出记忆；导入时只新增不冲突的内容，不覆盖或删除本机已有记忆。

不影响实时对话

保存与查找在后台进行；即使记忆暂时不可用，数字人仍会继续正常交流。

记忆由用户掌控：正式记忆不会自动删除；只有长期未确认的低可信度候选会在 30 天后自动清理。
